# 📂 'sleepy' 앱 프로젝트 디렉토리 구조 가이드

이 문서는 'sleepy' 앱의 소스 코드 구조를 설명합니다. 이 구조는 앱의 확장성과 유지보수성을 높이기 위해 기능 중심(Feature-First)으로 설계되었습니다.

---

## 🌳 최상위 구조

```
lib/
├── main.dart       # 앱의 시작점
└── src/            # 모든 소스 코드가 위치하는 루트
    ├── core/       # 앱의 핵심 기반
    ├── features/   # 기능별 모듈
    └── shared/     # 공용 코드
```

## CORE
### `lib/src/core`
앱의 핵심 로직을 담당하며, 특정 기능에 종속되지 않고 여러 곳에서 공유되는 기반 코드들을 관리합니다.

- **`api/`**: 외부 서버와의 API 통신과 관련된 클라이언트, 데이터 소스 등을 관리합니다.
- **`models/`**: 앱 전체에서 공통으로 사용되는 데이터 모델(예: `SleepData`, `UserProfile`)을 정의합니다.
- **`services/`**: 블루투스, 데이터베이스, 수면 분석 등 핵심 비즈니스 로직을 서비스 형태로 구현합니다.
- **`router/`**: `GoRouter`를 사용한 앱의 전체적인 화면 이동(라우팅) 로직을 관리합니다.
- **`providers/`**: 앱의 전역 상태를 관리하는 `Riverpod` 프로바이더들을 정의합니다.

## FEATURES
### `lib/src/features`
앱의 각 기능(`onboarding`, `dashboard` 등)을 독립적인 모듈처럼 관리합니다. 이를 통해 기능 간의 의존성을 최소화하고 코드 파악을 쉽게 만듭니다.

- **`application/`**: UI와 비즈니스 로직을 연결하는 상태 관리 로직(예: `Riverpod`의 `Notifier`)이 위치합니다.
- **`domain/`**: (선택사항) 해당 기능의 순수 비즈니스 로직과 도메인 모델(Entity)을 정의합니다.
- **`data/`**: (선택사항) 데이터 소스(API, DB)와의 통신 및 데이터 가공을 담당하는 리포지토리(Repository)가 위치합니다.
- **`presentation/`**: 해당 기능의 UI(화면, 위젯) 코드가 위치합니다.

## SHARED
### `lib/src/shared`
여러 기능에서 공통적으로 재사용되는 UI 위젯이나 유틸리티 함수들을 관리합니다.

- **`widgets/`**: 공용 버튼, 로딩 인디케이터 등 여러 화면에서 재사용되는 위젯을 정의합니다.
- **`constants/`**: 앱의 공통 색상, 폰트 스타일, 패딩 값 등 디자인 시스템과 관련된 상수들을 관리합니다.
- **`utils/`**: 날짜 포맷팅, 유효성 검사 등 특정 기능에 종속되지 않는 공용 유틸리티 함수들을 관리합니다.
